# Roadmap

## Phase 0 — Foundation

Repository, agent workflow, architecture, threat model, security specification, permissions, extension/companion scaffolding, IPC.

## Phase 1 — Vault

Encrypted vault, database, lock/unlock, security tests.

## Phase 2 — Job model

Jobs, snapshots, history, search.

## Phase 3 — Browser integration

LinkedIn, Indeed, generic company career pages, manual fallback.

## Phase 4 — Repost detection

Identity, fingerprints, similarity, review.

## Phase 5 — Diff engine

Text, bullets, ordering, requirements, ranking.

## Phase 6 — UI

Job list, detail, history, comparison, highlights, tailoring keywords.

## Phase 7 — Hardening

Security/privacy/permission/network audits, robustness, encrypted backup, documentation.

## Phase 8 — Future

Autofill, application tracking, resume/cover letters, local AI, interview preparation.
